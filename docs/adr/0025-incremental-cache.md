# ADR 0025 — Full analysis equality and atomic reusable evidence

Status: accepted for M5-T01

The existing `CanonicalState` already retains normalized source/input hashes, syntax facts/spans/diagnostics and typed graph/provenance/confidence/unresolved records, excluding operational origin/time/generation and database row IDs. Add a difference-section API without weakening that contract. `CanonicalAnalysis` adds complete module/export/import/lookup/config/discovery evidence and missing auxiliary probes. Normalize record-set order only; lookup attempts/routes and witness paths remain ordered. Raw effective-config input fingerprints deliberately retain byte/comment changes under existing policy.

Persist an `AnalysisCache` alongside each cold generation: raw content hashes, optional symbol signature hashes (including class/member shape), versioned module export fingerprints, complete module evidence/dependencies and missing config/ignore/package probes. A missing signature hash never proves equality. Fingerprints are derived from trusted captured analysis, not TypeScript semantic proof. Validate project/config/policy/file membership and recompute fingerprint records before storage/reuse; checksum/seal validation detects corruption, not malicious rewriting or an untrusted producer.

Schema v2 adds `analysis_artifacts`. Initialize a new database using migrations 1 and 2 and verify both checksums. Reject existing schema-v1 databases with explicit rebuild instructions; no silent migration or destructive deletion. `publish_analysis` inserts cache, graph/facts/captured bytes and active-generation pointer in the same transaction, and the generation seal includes the complete optional cache. Existing low-level `publish` supports generic caller snapshots without an analysis artifact; incremental indexing must report a full fallback when that cache is unavailable. Missing/corrupt authoritative cache data cannot silently become a cache hit. Artifact records share the 64 MiB per-record, 256 MiB aggregate and million-row storage bounds.

The old `modules-N.json` sidecar remains a derived export/debug artifact; it is not an authority or required for reuse. Worktree freshness and capture verification remain separate from canonical equality. T01 adds neither incremental publication nor early cutoff: T02 first reuses unchanged parses with full resolution, T05 establishes generated equality/round-trip guards, and T03 may then apply proven selective rules. Performance is not measured.
