# M1 — Source understanding

Status: done

All seven M1 cards, including the discovery/parser and extraction reviews, are integrated and verified. Ripple now discovers supported TS/TSX files, captures source/config/ignore inputs, parses bounded syntax trees, extracts supported stable symbols and signature/body fingerprints, and retains imports/exports, lexical bindings/scopes and runtime reference provenance. `ripple inspect` exposes one discovered file as human or versioned JSON output with explicit diagnostics and incomplete-analysis status.

The milestone gate passed 114 Rust tests on macOS, including 14 CLI inspect tests, plus formatting, locked build, strict all-target Clippy, 18 planning tests and plan validation. Independent TS/TSX projections, full human goldens and source-span/ownership checks cover the demo. Repeated and relocated captures produce stable reports; CRLF, invalid inputs, skipped/ignored paths, malformed syntax, unsupported calls and terminal escaping have fixtures/tests. Temporary Git tests confirm no index or checkout changes. A clean temporary installed binary passed help/version and TS-human/TSX-JSON smoke, including a byte-stable JSON repeat.

[CI on the integrated milestone source](https://github.com/adhyannsingal/ripple/actions/runs/41236840736) passed on Linux, macOS and Windows, including inspect demos. RustSec checked 122 packages with zero known vulnerabilities/warnings; code review is not proof of vulnerability absence.

This is source understanding, not dependency resolution or an impact-analysis release. Inspection currently captures the whole root and publishes no freshness-verified generation. Config semantics, resolved graph edges, SQLite storage, Git comparisons, incremental analysis and related-test selection remain later work. No performance or compiler-oracle accuracy was measured.
