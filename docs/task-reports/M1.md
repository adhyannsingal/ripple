Status: done

All nine M1 cards, including the discovery/parser and extraction reviews, are integrated and verified. Temporary Git tests confirm no index or checkout changes. A clean temporary installed binary passed help/version and TS-human/TSX-JSON smoke, including a byte-stable JSON repeat.
