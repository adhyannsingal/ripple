# M0 — Contracts and bootstrap

Status: done (2026-10-29)

All five required tasks are integrated with task-level code commits and validation records in the ledger. This milestone supplies a buildable seven-crate workspace, CLI help/version, reproducible fixture helpers, validated source/identity/syntax records, confidence-aware graph/witness contracts and typed index/revision/canonical-state contracts. Scoped ADRs describe decisions and consumer responsibilities.

The gate passed formatting, strict locked Clippy, 46 Rust tests, 15 Python tests, planning validation, documentation links and dependency-boundary review. [CI on integrated code 6039fc2](https://github.com/adhyannsingal/ripple/actions/runs/40976184529) passed on Linux, macOS and Windows. Canonical-state tests include retained diagnostics/confidence/provenance, ordering and serialization; revision tests preserve base-only deletion evidence.

This is a foundation gate, not a functioning analysis release: no scanner/extractor/resolver, Git adapter, SQLite index or impact BFS exists yet. Contract tests with synthetic manifests do not prove real hashing, transaction atomicity, filesystem freshness or incremental correctness. Those remain explicit later tasks. No performance/accuracy numbers are claimed.
