# M2 — Persistent graph and impact

Status: review — local implementation complete; integrated platform gate pending.

The seven M2 cards supply configured relative/alias lookup, re-export origins and uncertainty, supported lexical calls/references, atomic captured-input SQLite generations, deterministic dual-track reverse traversal and cold index/status/impact commands. Inspect remains available as a syntax-only debugging command.

The gate uses `fixtures/cold-index/`: a change seed at lib.ts::a reaches caller and a.test.ts through a two-hop symbol-backed witness; b.test.ts appears only in conservative module fallback. Human/JSON output retains both evidence kinds, original spans/rules, confidence and explicit limits. Fresh index reopens across processes and counters agree with stored facts. Unchanged cold builds have equal canonical state.

Local verification passed 222 Rust tests, strict Clippy and the clean-installed capability smoke. Builder hooks verify source edit/add/delete/config/ignore/HEAD changes cause retry/failure with the previous generation preserved. One-off changes retry; changes after verification cause subsequent stale-query errors. Storage fault, corruption, version, contention and reader-race tests remain passing. The install smoke also checks that user Git-index bytes are unchanged.

Final integrated planning/build/format/install checks, three-platform CI and security verification are recorded after completion in the [ledger](../planning/tasks.json) and [security review](../reviews/M2-security-verification-2026-11-02.md).
